# Work KG — спецификация дизайна для фронтенда

Telegram Mini App для поиска работы и подработки в Бишкеке. Две роли в одном аккаунте: **исполнитель** (ищет работу или подработку) и **работодатель** (компания или частное лицо). Любой пользователь может быть обоими.

Главные идеи продукта, которые объясняют дизайн:
- В центре проверенные **компании**: обложка, рейтинг, «Платит вовремя», отзывы сотрудников.
- Контакт идёт **напрямую в WhatsApp или Telegram**. Кнопки «Откликнуться» нет.
- Отзыв можно оставить только после **подтверждённой работы**. Подтверждение делается одним вопросом «Работали вместе?», и оценка звёздами означает «да».

Скриншоты лежат в `screenshots/` и пронумерованы, в тексте ниже на них стоят ссылки вида `[01]`.

## 0. Основы

### Макет
- Базовая ширина 390 px, все размеры ниже указаны для неё. На ширине 360–430 px растягивается по ширине, меняются только поля.
- Фон экрана `--bg`. Поля экрана: сверху 18, по бокам 20, снизу 120 (место под таб-бар).
- Экраны с обложкой (профиль компании, вакансия) идут без полей сверху и по бокам: обложка от края до края, контент ниже с полями 20.
- Вертикальный ритм: заголовок секции отстоит на 30 сверху и 14 снизу, карточки в списке идут через 12.

## 2. Навигация

**Таб-бар** `[01]`: плавает, отступ 16 слева, справа и снизу (+ safe area снизу). Высота 70, r26, фон `rgba(14,14,16,.94)` + `backdrop-filter: blur(14px)`, тень `0 14px 40px rgba(14,14,16,.3)`.

|---|---|---|
| Главная | home | 3. Главная |
| Компании | building-2 | 4. Компании |
| ＋ (по центру) | plus | открывает лист «Что публикуем?» (6.1) |

**Где таб-бар скрыт:** профиль компании, вакансия, формы, отзыв, вывод, бот-превью. На этих экранах работает Telegram `BackButton` и своя круглая кнопка «назад» вверху слева.

**Карта переходов**
- Главная → карточка компании → Профиль компании → Вакансия
- Главная → карточка вакансии → Вакансия → имя компании → Профиль компании
- Главная → «Ещё N ›» → лист «Все сферы»
- ＋ → лист → одна из 4 форм → после публикации: Сделки (работодатель) или Профиль
- Сделки → «Закрыть набор» → лист «Кого наняли?»; «Оставить пару слов» → Отзыв
- Профиль → Бонусы → Вывод

6. Кнопка red block «Вывести 62,50 сом» (opacity .4 при ошибке). Успех: Профиль + тост «Заявка на 62,50 сом принята».

Курс: 100 баллов = 5 сом, минимум 1 000 баллов. Формат денег: «62,50 сом» (запятая, пробел между тысячами: «1 250»).

## 12. Состояния и пограничные случаи
| Случай | Поведение |
|---|---|
| Длинное название должности или компании | максимум 2 строки, дальше многоточие (`-webkit-line-clamp: 2`) |
| Длинная цитата на обложке | максимум 2 строки, ширина до 70% |
| Нет фото компании | фирменный градиент + буква логотипа |
| Фото не загрузилось | `onerror` → градиент |
| Нет рейтинга | «Новичок» вместо звёзд |
| Зарплата не указана | «Договорная» (никогда не показывать пустое место или одно 💵) |
| 0 вакансий в сфере | текст «Пока нет вакансий в этой категории» |
| Счётчик Сделок = 0 | бейдж скрыт |
| Медленная сеть | скелетоны; кнопки с запросом показывают спиннер и блокируются |
| Офлайн | тост «Нет интернета» + повтор при возвращении сети |
| Склонения | 1 вакансия / 2 вакансии / 5 вакансий; 1 год / 2 года / 5 лет; 1 отзыв / 2 отзыва / 5 отзывов |
| Числа | разделитель тысяч — пробел: 35 000, 1 250 |

## 13. Доступность
- Минимальная зона нажатия 44×44: кнопка «назад», сердечко, ×, звёзды (46).
- У кнопок с иконкой без текста есть `aria-label`: «Назад», «Сохранить», «Поделиться», «Создать», «Уведомления», «Оценка 1 из 5»…
- StarInput — это `radiogroup`, каждая звезда — `radio`.
- Нижний лист: `role="dialog"`, `aria-modal`, фокус внутрь, Esc и тап по фону закрывают.
- Тосты: `role="status"` (`aria-live="polite"`).
- Контраст: muted #8A8A93 на #F6F5F2 используется только для второстепенного текста размером от 12.5.
- Видимый фокус: рамка 2 px ink, отступ 2.
