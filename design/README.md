# Work KG: пакет дизайна для разработки

| Файл | Что внутри |
|---|---|
| `CLAUDE.md` | Инструкция для Claude Code: источники, правила, стек, порядок работы. Claude Code читает её автоматически |
| `DESIGN_SPEC.md` | Полная спецификация: токены, компоненты, все экраны, состояния, тексты, ошибки, доступность |
| `tokens.css` | Цвета, шрифт, тени, радиусы. Подключается в проект как есть |
| `src-types.ts` | Типы данных, каталог профессий, сферы и мок-данные из прототипа |
| `screenshots/` | 28 экранов 390×844 @2x — эталон внешнего вида |
| `reference/prototype.html` | Кликабельный прототип, открывается в браузере |
| `reference/styleguide.html` | Все компоненты на одной странице с параметрами |

## Как отдать Claude Code

1. Положите папку в корень репозитория фронтенда, например в `design/`. Если `CLAUDE.md` в репозитории уже есть, добавьте в него строку: «Дизайн и правила вёрстки — в design/CLAUDE.md».
2. Скажите Claude Code:

> Прочитай design/CLAUDE.md и design/DESIGN_SPEC.md. Сначала сделай токены и базовые компоненты из раздела 1 и покажи страницу-витрину. Потом экраны по порядку. После каждого экрана сравни свой скриншот с design/screenshots и исправь расхождения.

3. Лучше просить по одному экрану за раз: так проще проверять результат.
