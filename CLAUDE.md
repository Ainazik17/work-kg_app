# Work KG — фронтенд (Telegram Mini App)

Дизайн и правила вёрстки — в design/CLAUDE.md.

- Токены: `src/styles/tokens.css` (копия `design/tokens.css`, менять только вместе), стили компонентов: `src/styles/wk.css`.
- Базовые компоненты: `src/ui/wk.tsx`; экран объявления: `src/ui/ListingView.tsx`.
- Витрина компонентов (только dev): `npm run dev` → `http://localhost:3000/#/ui-kit`.
- Поля API и форм не переименовывать: дизайн меняет только вёрстку.
